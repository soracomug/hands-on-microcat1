# 3: SIM の開通と SORACOM Harvest Data の設定

この章では、通信に利用する SIM を使える状態にし、データ受け取り先として SORACOM Harvest Data を有効化します。

## 想定時間

10 分

## この章のゴール

- 利用する SIM を SORACOM に登録または開通する
- SIM グループを確認する
- SORACOM Harvest Data を ON にする

## 手順の下書き

1. SORACOM ユーザーコンソールへログインする
2. 利用する SIM の状態を確認する
3. 必要に応じて SIM を開通する
4. SIM グループの設定画面を開く
5. SORACOM Harvest Data を有効化する

## この章で掲載する内容

- コンソール画面の遷移
- Harvest を ON にする画面のスクリーンショット
- よくあるつまずきポイント
