# 4: SORACOM へデータ送信して Harvest で確認

この章では、microcat1 から SORACOM へデータを送信し、Harvest で受信結果を確認します。

## 想定時間

10 分

## この章のゴール

- microcat1 からセルラー通信でデータを送る
- Harvest Data 上で受信したデータを確認する
- 送信内容と表示内容の対応を理解する

## 手順の下書き

1. 通信設定済みのサンプルコードを用意する
2. 送信するデータ項目を確認する
3. コードを書き込んで実行する
4. SORACOM ユーザーコンソールで Harvest Data を開く
5. 送信したデータが表示されることを確認する

## この章で掲載する内容

- データ送信サンプルコード
- 実行ログの例
- Harvest 画面の確認方法
